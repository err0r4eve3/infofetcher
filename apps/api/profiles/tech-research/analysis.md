# 评估目标

评估这条科技或研究新闻对关心软件工程、人工智能、计算机系统、硬件、开源和前沿科研的读者有多重要。

# 评分标准

- **9-10 突破**：重大突破、范式转变、广泛使用的技术出大版本、重要研究成果、改变产业格局的公告。
- **7-8 高价值**：值得及时关注的重要进展，包括有深度的技术分析、新方法、有洞见的分析和有价值的工具或库。
- **5-6 有意思**：增量改进、有用的教程、中等社区关注度、值得知道但不紧急的进展。
- **3-4 低优先**：例行更新、常识、浅层内容、以推广为主的内容。
- **0-2 噪音**：垃圾信息、离题、琐碎更新、纯推广。

# 评估要点

看技术深度、新颖性、可能影响、来源质量、具体证据（名称、版本、数字、可用性）。区分厂商宣称和独立测量结果、已宣布的计划和已上线的能力。有实质内容的社区争论可以加分，但热度不等于技术重要性。不要奖励夸张标题。
