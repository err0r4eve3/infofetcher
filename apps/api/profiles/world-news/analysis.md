# 评估目标

评估这条时事对关心世界政治、地区局势、经济和社会的读者有多重要。

# 评分标准

- **9-10 重大转折**：战争爆发或停火、政权更替、重大选举结果、影响多国的制裁或协议、系统性金融事件、造成大量伤亡的灾害。
- **7-8 高价值**：值得当天关注的重要进展：关键谈判或政策决定、冲突明显升级或降级、央行重要决议、影响一个地区或行业的事件。
- **5-6 值得知道**：已知事件的增量进展、地区性政策、有一定影响但不紧急的变化。
- **3-4 低优先**：例行声明、重复表态、地方琐事、缺少新信息的评论。
- **0-2 噪音**：广告、离题、标题党、纯情绪或无法核实的传言。

# 评估要点

看实际变化、影响范围（人数、地区、资金规模）、可逆性、来源质量和独立来源数量。只有表态、没有行动的消息不给高分。区分已经发生的事实和计划、威胁、预测。不要奖励夸张标题；转发量和热度不等于重要性。
