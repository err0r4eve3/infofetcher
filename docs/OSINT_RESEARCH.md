# 自研本地 OSINT 调查

更新：2026-09-27。调查 Agent 在 Rust 服务内执行，不使用第三方检索、存档或模型接口，无需配置 API Key。原有新闻摘要/翻译仍属于各自独立流程，本次修改仅覆盖 OSINT 调查。

## 流程与算法

1. 读取事件中质量排序前 30 篇未静音材料，过滤空正文。保留标题、原文 URL、源报发布时间、抓取时间和全文指纹。
2. 使用现有 Tantivy 站内索引检索最多 60 个候选，再经数据库过滤过期索引、静音来源和本事件材料，返回最多 12 条相关线索。检索词默认事件标题，可手动缩短；输入取最多 12 个字面词项，以 OR 检索。中文沿用现有索引分词，不提供跨语言语义检索。相关材料不自动混入当前事件。
3. 按发布者、规范链接、完整正文指纹关系做传递合并。导出正文限制 12,000 字符，但合并使用完整正文指纹，避免正文前缀相同造成误合并。
4. 对规范化正文的前 4,000 个字母/数字字符生成五字符片段集合；两篇均至少有 80 个不同片段、Jaccard 相似度达到 85% 时标为疑似转载。只作为人工检查线索，不改变已知依赖分组。
5. 缺失发布时间保持空值；源报发布时间超过抓取时间 24 小时的材料提示核对时区、预告日期和元数据。不以抓取时间冒充事件发生时间。
6. 每篇最多抽取 3 条、每条 16–360 字符的完整原文句段，优先更正措辞，其次含数字句段。支持中文句末标点，保留英文小数点。完全相同的片段合并来源 ID，按依赖组计数。只标注阿拉伯数字，未提取到数字不代表没有数量信息。
7. 对抽取片段将数字替换为占位符；句式完全相同、数字序列不同且涉及多篇材料时提示检查统计口径、单位和时间。这可能是正常更新，不做语义冲突判断。
8. 生成包含规则发现、来源引用、片段、时间、过程和局限的 JSON。规则分析完成显示 `analyzed`，少于两个已知依赖组显示 `insufficient`，不输出真实/虚假评分。

来源陈述、相同文字和报道数量都不直接等于事实成立。规则无法覆盖改写、跨语言转载、影像鉴伪、实体消歧或细致语义矛盾。工具只处理当前已采集的材料，不能保证站外覆盖。

## 网络与存储边界

调查接口只访问本地数据库和索引，不构造 HTTP 客户端、不启动程序、不调用模型。两个并发槽位与同事件 PostgreSQL 事务锁限制重复任务，异步调查等待预算 20 秒；有界文本比较放在阻塞线程，取消请求不强制终止已经开始的短 CPU 计算。

“抓取证据”仍是独立的用户动作，直接访问该事件已入库文章的原站 URL，沿用私网/重定向检查与精确字节导出。第三方存档查询已停用；旧请求中的 `include_archive=true` 在任何页面抓取前返回 400。历史记录原样保留。

报告不自动入库、不发布快讯、不推送。离开或刷新页面前需手动导出。`text_sha256` 对应导出文本；`full_text_sha256` 对应完整规范化正文，不是原始 HTTP 字节哈希。精确字节证明仍使用“抓取证据”导出文件。

## 接口变化

- `GET /api/v2/osint/tools`：`agent=native-osint-v2`、`network_access=false`、`model_required=false`。
- `POST /api/v2/events/{id}/osint/research`：`{ "query"?: string }`，查询词 1–240 字符。
- 导出格式升级为 `rss-osint-research-v2`，增加 `fragments`、`findings`、`dependency_groups`、完整正文指纹和截断标识。
- 旧 `provider` / `analyze` 参数返回 422；外部检索配置及专用模型入口已经移除。

## 验证

```sh
cargo test -p infofetcher-api
cargo clippy -p infofetcher-api -- -D warnings
npm run typecheck:web
npm run build:web
```

数据库集成测试使用已建表的隔离 PostgreSQL，设置 `RSS_OSINT_TEST_DATABASE_URL` 后运行：

```sh
cargo test -p infofetcher-api research_roundtrip_with_postgres -- --ignored
```

覆盖真实会话/API/SQL、站内索引与数据库过滤、同事件锁、旧外部参数拒绝、第三方存档请求拒绝。模型端点设置为本地计数服务，验证调查后模型请求数为零。精简本机 PostgreSQL 如缺少扩展，测试建表可跳过扩展声明和 trigram 索引；这只能验证本流程的表/查询，不代表完整生产迁移成功。
